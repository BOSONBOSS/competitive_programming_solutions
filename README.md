## Repository Structure

Solutions are organized primarily by platform domain, categorized by topic, and indexed using 4-digit zero-padded problem numbers:

```
competitive_programming_solutions/
├── leetcode.com/
│   ├── prefix-sum/
│   ├── 2d-arrays/
│   ├── two-pointers/
│   ├── hash-map/
│   └── ...
├── geeksforgeeks.org/
│   ├── arrays/
│   ├── binary-search/
│   ├── prefix-sum/
│   └── sliding-window/
├── codeforces.com/
├── cses.fi/
├── codechef.com/
├── atcoder.jp/
└── topics/
    ├── basic-math/

    └── hashmap/
```

## Compilation and Execution

All solutions are written targeting modern C++ standards (**C++17 / C++20**).

To compile and run any `.cpp` file locally:

```bash
# Compile with C++20 standard and optimizations
g++ -O2 -std=c++20 path/to/solution.cpp -o solution

# Execute
./solution
```
